# CBDT — Central Bank Digital Token (CBDT) Repository

Krātuve, kas satur smart līgumus, API vārteju, paneli un rīkus Central Bank Digital Token projektam.

Ātra sākšana

- Palaist API testus:
  ```bash
  cd api
  npm ci
  npx vitest
  ```
- Palaist conciliācijas referenci:
  ```bash
  cd tools/reconciliation-ref
  node index.js
  ```

Skatīt galveno README un `docs/` sīkākiem norādījumiem.
