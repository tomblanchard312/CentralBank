# CBDT — Central Bank Digital Token (CBDT) Repository

Shramba, ki vsebuje pametne pogodbe, API prehod, nadzorno ploščo in orodja za projekt Central Bank Digital Token.

Hiter začetek

- Zaženi API teste:
  ```bash
  cd api
  npm ci
  npx vitest
  ```
- Zaženi referenčno storitev za uskladitev:
  ```bash
  cd tools/reconciliation-ref
  node index.js
  ```

Oglej si glavni README in `docs/` za podrobna navodila.
