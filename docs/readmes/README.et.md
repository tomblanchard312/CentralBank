# CBDT — Central Bank Digital Token (CBDT) Repository

Hoop, mis sisaldab smart contract'e, API-väravat, armatuurlaua ja tööriistu Central Bank Digital Token projekti jaoks.

Kiirstart

- Käivita API testid:
  ```bash
  cd api
  npm ci
  npx vitest
  ```
- Käivita reconciliatsiooni referents:
  ```bash
  cd tools/reconciliation-ref
  node index.js
  ```

Vaata üksikasjade jaoks peamist README-d ja `docs/`.
