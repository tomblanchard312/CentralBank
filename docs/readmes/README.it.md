# CBDT — Central Bank Digital Token (CBDT) Repository

Repository contenente smart contract, API gateway, dashboard e strumenti per il progetto Central Bank Digital Token.

Avvio rapido

- Eseguire i test API:
  ```bash
  cd api
  npm ci
  npx vitest
  ```
- Avviare il servizio di riconciliazione di riferimento:
  ```bash
  cd tools/reconciliation-ref
  node index.js
  ```

Vedere il README principale e `docs/` per le istruzioni dettagliate.
