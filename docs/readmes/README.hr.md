# CBDT — Central Bank Digital Token (CBDT) Repozitorij

Repozitorij koji sadrži pametne ugovore, API gateway, nadzornu ploču i alate za projekt Central Bank Digital Token.

Brzi početak

- Pokreni API testove:
  ```bash
  cd api
  npm ci
  npx vitest
  ```
- Pokreni referentnu reconciliaciju:
  ```bash
  cd tools/reconciliation-ref
  node index.js
  ```

Pogledajte glavni README i `docs/` za detaljne upute.
