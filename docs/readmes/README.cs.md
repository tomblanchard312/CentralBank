# CBDT — Central Bank Digital Token (CBDT) Repository

Repozitář obsahující smart kontrakty, API bránu, dashboard a nástroje pro projekt Central Bank Digital Token.

Rychlé spuštění

- Spustit testy API:
  ```bash
  cd api
  npm ci
  npx vitest
  ```
- Spustit referenční reconciliaci:
  ```bash
  cd tools/reconciliation-ref
  node index.js
  ```

Podrobné pokyny naleznete v hlavním README a v `docs/`.
